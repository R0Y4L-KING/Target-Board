## Live site

Hosted with GitHub Pages: https://r0y4l-king.github.io/Target-Board/

## Editing

Everything is in a single `index.html` file (inline CSS, no build step). To change a link, edit the `href` of the matching `.neon-btn` anchor and commit to `main` — Pages redeploys automatically.
